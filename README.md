# The Maze Code — Online Python Sessions 🐍

Welcome to the official repository for **The Maze Code** online Python sessions! 

We are a dedicated group of university students learning, coding, and growing together through collaborative online study sessions. Using **Jupyter Notebooks** as our primary interactive environment, our goal is to bridge the gap between foundational programming concepts and real-world applications. 

Our learning roadmap starts with mastering **Object-Oriented Programming (OOP)** in Python, building a wide variety of hands-on projects to solidify our skills, and progressively advancing into the exciting worlds of **AI Engineering and AI Research**.


## 🚀 Getting Started

If you are part of our study group or want to follow along with our notebooks locally on your machine, follow these steps:

### Prerequisites

* [Python 3.8+](https://www.python.org/downloads/)
* [Jupyter Notebook](https://jupyter.org/install) or [JupyterLab](https://jupyter.org/) (or [VS Code](https://code.visualstudio.com/) with the Python & Jupyter extensions)

### Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/themzcd/themazecode-online-sessions-python.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd themazecode-online-sessions-python
   ```

3. **Launch Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```
   *Once Jupyter opens in your browser, navigate to either the **Session Notebooks** or **Projects** folder to open and run the `.ipynb` files.*

## Because this is a shared space for university students learning together:
